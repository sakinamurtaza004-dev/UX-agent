UX Audit Buddy is a Chrome extension that audits the web page you are viewing for usability, accessibility and manipulative-design problems, and lets you save a report. This policy explains what data it handles.

In short

  • The audit runs on your device. Your audits, reports and settings are stored only in your browser.
  • Nothing is sent anywhere unless you choose to run the optional AI review and confirm a consent box.
  • We do not use analytics or advertising trackers, do not sell data, and do not load remote code.

You can turn history off, delete a single audit, delete all history, or export your data from the extension's History page. Uninstalling the extension removes this data.

The optional AI review: what is sent

The AI review only runs when you click Run AI review after ticking the consent box. It then sends the following to a review server and, through it, to Anthropic's Claude AI service to produce the review:

  • The page address (without query string or #fragment), page title, meta description, headings, navigation and button labels;
  • Up to about 9,000 characters of the page's visible text. Text you typed into form fields is not included;
  • A summary of the automatic findings (check names, counts, scores);
  • Optionally, a screenshot of the part of the page visible on screen (you can untick this);
  • The random install ID, and an access token only if you entered one.

Please do not run the AI review on pages that show private information (email, banking, health, internal company tools). The extension warns on pages that look private, but cannot detect everything.

  • The review server, operated by [[WHO OPERATES THE SERVER AND WHERE IT IS HOSTED]]. The server does not store page content or screenshots and does not write them to its logs. Its logs record only technical details such as time taken, model name and token counts. It keeps request addresses in memory for up to one hour to apply rate limits. Its hosting provider ([[HOST NAME]]) may keep standard network logs of its own.
  • Anthropic, which processes the request to generate the review under its own terms and privacy policy: [[ADD THE CURRENT LINK TO ANTHROPIC'S PRIVACY POLICY AND CHECK ITS DATA-RETENTION TERMS FOR API USE]].

If you set up your own review server in the extension's settings, the data goes to the server you chose instead, and that server's operator is responsible for it.

The AI review is generated by an AI model, can be wrong, and is labelled as AI-generated wherever it appears.

What we do not do

  • No analytics, advertising, tracking or profiling.
  • No selling or sharing of your data for advertising, and no use of it for purposes unrelated to producing your audit and review.
  • No remotely hosted code: all of the extension's code ships inside the extension.
  • No reading of any page unless you open the extension on it and ask for a scan (the extension asks Chrome only for the permissions listed below).
